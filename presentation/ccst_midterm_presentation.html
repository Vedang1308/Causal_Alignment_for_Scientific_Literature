Problem Definition
The Two Critical Blind Spots in Scientific Search
Blind Spot 1 Disjoint Vocabularies Conceal Analogies

Biology / Epidemiology: Models respiratory viral propagation using Susceptible-Exposed-Infectious-Recovered (SEIR) network clustering.

Computer Systems: Models self-replicating worm malware across software-defined network (SDN) switches using identical graph dynamics.

→ Dense Embeddings (SBERT, Contriever) score them as completely unrelated due to zero lexical overlap (0% Analogy Recall)!

Blind Spot 2 Superficial Opposites Cause False Contradictions

Paper A (Clinical Trial): Calcium channel blocker reduces systemic vascular resistance in human adults at therapeutic doses.

Paper B (Toxicology): Calcium channel blocker induces paradoxical reflex vasoconstriction in murine models under toxic overdoses.

→ Standard NLI / LLMs focus only on "reduces" vs "increases", generating a catastrophic 40%+ False-Contradiction Error Rate!

Proposed Solution
Our Proposed 5-Way Scientific Relation Taxonomy
1. Agreement
Both papers report congruent causal effects under compatible physical context and population.
2. Cross-Domain Analogy
Isomorphic causal mechanism graph topology expressed across disjoint scientific vocabularies.
3. Contradiction Candidate
Opposing causal polarity (±1 vs −1) under verified identical material context.
4. Contextual Heterogeneity
Opposing outcome directions explained by divergent physical scope (species, dose, environment, or time horizon).
5. Insufficient Comparability
Incompatible core interventions or insufficient textual evidence to evaluate mechanism alignment.

Proposed Solution
CCST: Context-Conditioned Signed Partial Transport
Equation (2) CCST Alignment Objective
$$\mathcal{D}_{\text{CCST}}(G_i, G_j) = \min_{T \ge 0} \left[ \sum M_{uu'} T_{uu'} + \alpha \sum L_{uv, u'v'} T_{uu'} T_{vv'} + \lambda_u U(T) + \lambda_g \Phi_{\text{gate}}(G_i, G_j) \right]$$
1. Partial Transport
$$\lambda_u U(T) = 2\lambda_u(1 - \mathbf{1}^\top T \mathbf{1})$$ Allows peripheral or irrelevant claims to remain unaligned without corrupting the core mechanism match.
2. Signed vs. Unsigned
$$\Delta_{\text{sign}} = D_{\text{signed}} - D_{\text{unsign}}$$ Isolates true directional polarity flips (+1 vs -1) from underlying structural graph topology.
3. Context Gating
$$\Phi_{\text{gate}}(G_i, G_j)$$ Penalizes contradiction declarations when species, dosage, or environment differ.

Scalability Architecture
Tri-Index Sparse Candidate Retrieval Engine
Solving the O(N²) Bottleneck
Comparing 2,054 papers brute-force requires 1,999,000 exact alignments. We prune the search space to an empirical \(O(N \log N + N \cdot k)\) via a union of 3 sparse indexes:
I_sem: Semantic
FAISS dense inner-product index over normalized 384-d Sentence-BERT vectors (top-\(k_s = 15\)).
I_graph: Structural
2-iteration Weisfeiler-Lehman (WL) graph hashing index over unsigned topologies (top-\(k_m = 15\)).
I_ctx: Contextual
Inverted bitvector index filtering compatible physical scope dimensions (top-\(k_c = 10\)).
